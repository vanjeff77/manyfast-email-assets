# 노션 이메일 CRM 페이지 이미지 첨부 가이드

이 폴더에 있는 **12장 이미지**를 노션 각 페이지의 해당 자리에 드래그해서 첨부하시면 됩니다.

## 노션 첨부 방법

1. 노션 페이지 열고, 교체할 이미지 자리(현재 docs.manyfast.io 링크로 표시된 곳)를 클릭
2. `/` 입력 후 `이미지` 선택 → `업로드` 탭
3. 아래 매핑표에 있는 파일을 드래그
4. 기존 링크 이미지는 삭제

또는 **탐색기에서 파일을 열어놓고 노션 페이지에 바로 드래그**해도 됩니다.
