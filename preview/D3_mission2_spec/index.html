3분이면 PRD가 와이어프레임, 기능명세서, MCP 연동까지 이어져요.
재훈님, 매니패스트가 진짜 힘을 발휘하는 건 지금부터예요.
이틀 전에 채팅으로 첫 PRD 초안을 만드는 미션을 드렸어요. 실제로 완성해보셨다면 이 메일이 특히 즐거우실 거예요.
오늘 미션은 방금 만든 그 PRD 하나를 기능명세서, 유저플로우, 와이어프레임으로 확장하고, MCP 연동으로 바로 개발까지 잇는 것이에요. 3분이면 됩니다.
왜 이게 중요할까요
PRD 넘겼는데 개발자가 되묻는 미팅, 다들 경험해보셨을 거예요.
"이 기능 어디에 붙는 화면이에요?"
"이 예외 케이스에서 어떻게 처리해요?"
"여기 정책이 앞뒤가 안 맞는데, 어떤 게 맞아요?"
기획서가 사람 눈에만 읽히도록 쓰여 있으면, 개발자도 AI 도구도 매번 되물어야 하는 상황이 반복돼요.
"기획자가 넘긴 문서 안에는 '화면 A에서 버튼 눌러 화면 B로 이동' 같은 표현이 흩어져 있죠. 사람이 읽으면 문제없어 보이지만, 개발자에게는 화면들을 하나하나 매핑해야 하는 재해석 작업이 됩니다. 매 재해석마다 오해가 생기고, 오해는 결국 QA에서 터집니다."
매니패스트 블로그: 「개발자를 화나게 하는 기획서를 만들지 않으려면」 →

매니패스트가 만드는 PRD는 기능명세서, 유저플로우, 와이어프레임까지 순서대로 구조적으로 연결돼요. 그래서 각 단계가 자연스럽게 이어지고, 그 문서를 그대로 AI 개발 도구가 이해할 수 있습니다.

💙 오늘의 미션 (3분)
PRD 하나로 기능명세서, 유저플로우, 와이어프레임, 그리고 개발까지 5단계로 잇습니다.
Step 1. 어제 만든 PRD 프로젝트를 열어요
매니패스트 대시보드에서 어제 만드신 프로젝트를 열어주세요. 아직 만들지 않으셨다면 1편 미션부터 다녀오셔도 좋아요.
Step 2. 기능명세서를 확인해요
PRD에서 도출된 각 기능이 어떤 화면의 어떤 기능이, 어떤 예외를 포함해서, 어떤 API를 호출해야 하는지까지 구조화돼 나와요.
필요하면 채팅으로 "결제 예외 케이스 하나 더 추가해줘" 같은 수정 요청도 가능합니다.
Step 3. 유저플로우를 만들어요
기능명세서가 정리되면 [유저플로우 생성] 버튼을 눌러주세요. 각 기능이 어떤 순서로 이어지고 어디서 갈라지는지 사용자 관점에서 흐름이 정리됩니다.
유저플로우는 다음 단계인 와이어프레임의 근거가 돼요. 흐름이 잘 잡혀야 각 화면이 어디에 필요한지도 명확해집니다.
Step 4. 와이어프레임을 만들어요
PRD, 기능명세서, 유저플로우가 모두 준비되면 [와이어프레임 생성] 버튼 하나로 각 화면과 화면 간 전환이 자동으로 정리됩니다.
링크 하나로 개발자에게 공유하거나 PDF로 내려받을 수 있어요.
Step 5. MCP 연동으로 바로 개발까지
매니패스트 설정에서 MCP 연동 링크를 복사해서 Cursor나 Claude Code에 붙여넣으면, AI가 매니패스트 프로젝트를 직접 읽어갈 수 있어요.
이제 개발자 옆에서 이렇게 말하면 됩니다.
"매니패스트에서 리셀러 대시보드 기획 문서 읽어줘"
Claude Code가 MCP를 통해 PRD, 기능명세서, 유저플로우, 와이어프레임 전체를 읽고, 각 스펙이 코드에 실제로 구현됐는지 대조까지 해줍니다.
와이어프레임과 기능명세서 만들어보기
매니패스트 팀이 직접 겪은 사례
저희 매니패스트 팀도 리셀러 정산 대시보드를 만들 때 이 방식을 실험했어요.
"기획서에는 '리셀러 할인 코드는 Paddle과 연동되는 코드'라고 적혀 있었어요. 그런데 코드를 보니 createCode() 함수가 DB에 레코드만 만들고 Paddle API는 전혀 호출하지 않고 있었습니다. 리셀러가 할인 코드를 만들어서 공유해도, 유저가 그 코드를 입력하면 아무 일도 일어나지 않는 상황이었던 거죠."
"코드 리뷰로 안 잡힙니다. 단위 테스트도 통과해요. QA에서도 '코드 생성 됩니다'하고 넘어가기 십상이에요. 그런데 AI가 이해하는 기획서를 작성하니, 'Paddle 연동이라고 써있는데 코드에 Paddle 호출이 없네요?'라고 짚어준 거예요."
매니패스트 블로그: 「클로드로 10분 만에 짠 코드, 노션 기획서로 3시간 검수」 →

이 흐름이 매니패스트가 만들어내려는 세상이에요. 기획이 개발까지 끊김 없이 이어지는 세상이요.
